# Cleaning Taza, клининг в Астане

Одностраничный сайт для клининговой компании Cleaning Taza (проспект Тауелсиздик, 21/5, работает круглосуточно).

На странице: услуги (уборка квартиры, генеральная, после ремонта, химчистка мебели), скидки до 15%, фото до и после из 2ГИС, как заказать, отзывы из 2ГИС, частые вопросы, форма заявки, которая открывает WhatsApp компании, и контакты.

Сайт на чистом HTML, CSS и JS, без сборки. Тексты в `index.html`, стили в `style.css`, фото в папке `img`.
